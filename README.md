# DKManager25 - Danish Football Manager Game

A React + TypeScript football manager simulation game where you manage a Danish football club.

## Prerequisites

- **Node.js**: ^20.19.0 or >=22.12.0
- **npm**: 10.0.0 or higher

## Installation

```bash
npm install
```

## Development

Run the development server:

```bash
npm run dev
```

The app will be available at `http://localhost:5173` (or another port if 5173 is in use).

## Build

Create a production build:

```bash
npm run build
```

The optimized files will be in the `dist/` directory.

## Preview

Preview the production build locally:

```bash
npm run preview
```

## Game Features

- 🏆 Manage a Danish football club
- 👥 Build and manage your squad
- 💰 Handle transfers and budgets
- ⚽ Play matches and track results
- 🏟️ View stadium and team information

## Technologies

- **React 18** - UI framework
- **TypeScript** - Type safety
- **Vite** - Fast build tool
- **Tailwind CSS** - Styling
- **PostCSS** - CSS processing
